# Pecatho

Plataforma Pecatho — ecossistema de anunciantes e Pecatho Fans.

## Diretrizes
- Pecatho Fans é um subdomínio integrado ao ecossistema Pecatho.
- Todos os recursos funcionais existentes são baseline obrigatório.
- Desenvolvimento: GitHub + Supabase + Vercel.
- A arquitetura será portável para futura migração de infraestrutura para a Locaweb.
- Nenhum recurso existente será removido sem inventário, análise de dependências e decisão explícita.
